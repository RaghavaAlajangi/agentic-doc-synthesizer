# Sample Financial Data

This directory contains sample financial documents for testing your document upload and search functionality.

## Files

- `quarterly_report_q3_2024.txt` - Sample quarterly financial report
- `market_analysis_2024.txt` - Sample market analysis document

## Usage

Upload these files through your document upload endpoint to test:
- Document indexing and storage
- Semantic search functionality
- Agent document processing capabilities

You can also create your own financial documents for testing.
